# Dailies

A tiny website for tracking the small things that keep you well: get outside, move, hydrate, eat well, rest, connect.

- **No accounts, no server, no tracking.** Everything is stored in your browser (`localStorage`) and never leaves your device.
- **Resets every day** at local midnight.
- **Vanilla HTML, CSS and JavaScript.** No framework, no build step.

## Status

Exploring design directions. Open `index.html` in a browser to compare them; each lives in `designs/<name>/` and shares `designs/core.js` (the list of dailies, icons and on-device state).

## The dailies

Six on by default, more you can switch on:

| Default | Optional |
|---|---|
| Get outside · Move · Hydrate · Eat well · Rest · Connect | Breathe · Unplug · Create · Learn · Tidy · Be grateful · Play · Be kind |
